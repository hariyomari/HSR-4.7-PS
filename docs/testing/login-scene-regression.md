# 4.5 PROD 登录与场景回归

测试项目：[`scripts/LoginSceneRegression/`](../../scripts/LoginSceneRegression/)

从仓库根目录运行：

```powershell
dotnet run --project scripts/LoginSceneRegression/LoginSceneRegression.csproj -c Release
```

4.7 beta 的 `main` 基础修复移植覆盖 `ceea39e3`（模拟宇宙通用查询及小游戏查询）、`db2b4e7e`（队伍槽位和收藏）、`91ca26c1`（开拓者当前命途）、`afe3ead3`（遗器预设校验）和 `2cbb3975`（副本退出/登录恢复）。专门检查位于 `MainFixRegression.cs`，由上述入口运行，继续使用临时 SQLite 与内存 KCP，不操作真实玩家数据库。

- 通用查询用 `CCKJAEDDDCL.BBEKBJPHEJKFieldNumber` 判定功能解锁分支；4.7 为 `10`，4.6 为 `1`，保持请求顺序与重复项，其他分支不臆造状态。
- 社交玩法、宠物弹珠数据与周期试用宠物查询返回空但存在的子消息，避免客户端收到 null；补齐工具不选择 oneof、不添加列表项。处理器经源生成 opcode 注册验证。
- 按编号补齐普通队伍 `0..8`，按编号下发并保留额外队伍，当前空队伍回落到已有非空普通队伍。收藏使用 4.7 请求/响应 `762/780`，合法修改持久化，额外队伍及非法编号不可修改。
- 开拓者命途修复在任务开关覆盖生效后执行，不提前替尚未选择性别的剧情新号决定性别；同时修复异常命途、缺失当前命途数据和陈旧 `CurBasicType`，正常数据保持幂等。
- 遗器预设验证角色和库存、拒绝空方案及无内容/无效遗器更新；新增、改名、删除独立触发保存，以 SQLite 读回验证，不依赖其他操作顺带标脏。
- 缺少资源配置或运行记录的副本退出不抛异常或无响应；优先返回原入口，无效入口或指向副本的旧返回点使用默认出生点。登录在加载场景前修复孤立副本位置，保留正常运行和剧情占用的位置；重置通知保留空物品列表，重复退出只应答。

存档兼容：`LineupInfo.IsFavourite` 追加在 MemoryPack 原有五个成员之后，使用独立旧五成员契约验证旧存档读取及默认值 `false`，并验证 SQLite 往返；之后追加的 `IsVirtual`、`PlaneId`（剧情/Raid 试用的虚拟队伍）同样以截去尾部成员的旧数据验证默认值。部署前停止服务端并备份当前配置所指定的玩家数据库（SQLite 应在关闭后备份）；回滚时同时恢复移植前程序和数据库备份，旧程序不能保证读取新六成员队伍数据。本批无需更新协议生成结果或 `Config/Resource.bin`，不新增每次登录重置位置的配置；宠物系统和差分宇宙整体移植留作独立变更。客户端页面、动画和场景体验仍需实机验证。

角色装扮使用实际换装/脱下请求、内存 KCP 与临时 SQLite 验证：换装本身标记玩家为待保存，先下发保留等级、光锥和遗器的角色同步，再返回结果；拒绝不存在的角色、未知/未拥有或属于其他角色的装扮，重复换装只应答，恢复默认装扮不依赖皮肤解锁字典。回归使用实际库存物品验证装备归属及战斗序列化，并读取 SQLite 中的角色数据重新登录，检查过图与重登保持选定装扮和装备。

旧存档可能包含重复的基础角色记录（实际日志中的昔涟 `1415` 有一条已培养记录和五条空记录）。登录快照按基础角色 ID 保留服务端 `GetFormalAvatar` 同样选择的首条记录，避免后面的空记录覆盖装扮、等级和装备；原始存档记录不删除或合并，无需迁移、替换缓存或重建账号。新增角色及重复命途解锁不再追加相同基础角色，也不重置已存的命途数据。客户端装扮模型和装备页面仍需实机验证。

角色快速升级通过实际源生成 opcode 注册表、请求解析和内存 KCP 验证。官服 4.6 抓包 seq `36813-36829` 与 `dumper/Raw/cmdid-registry.txt` 确认请求命令枚举 `KELLLHMHFHL` 对应消息 `EKLIDIDKFHC`（cmd 376），响应枚举 `MILFFHPMLMN` 对应 `PMEMIDKDAFG`（cmd 357）；当前 4.7 分别使用 cmd 355/341，直接使用已生成的同身份消息及其当前字段号，不修改协议或缓存。请求的 `IGOOJKMPMDC`、`KLMIBJIKIBB` 分别为目标等级、目标突破阶，`BACAOLDADMC` 是经验书费用，`OAINNDAHIMG` 是单独的突破费用。

覆盖已突破角色使用 8/6/7 本经验书升级至 30 级、20 级未突破角色一次消耗经验书与资源表中的突破费用至 30 级/1 阶，以及返还 2 本物品 211（角色经验书）；角色已有经验参与退款计算。服务端先校验全部费用、库存、等级上限及开拓等级/均衡等级要求，成功后同步角色、信用点和最终材料余额再应答。失败路径覆盖缺角色、缺信用点/经验书/突破材料、少报突破费用、重复材料行、数量溢出、用光锥或光锥经验材料代替角色经验书、经验不足及非法目标；重复或并发相同请求只扣费一次。该验证使用临时玩家数据，不替代客户端快速升级 UI 实机测试。

测试使用随机 RSA 密钥、临时 SQLite 数据库与仅监听本机的 HTTP 服务；不会读取运营配置、连接生产服务器或改写现有数据库。场景测试读取当前 `Config/Resource.bin` 的副本，不重新生成缓存。临时产物路径在测试结束时输出。
